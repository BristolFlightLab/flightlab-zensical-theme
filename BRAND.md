# Brand notice

The stylesheet in this repository is MIT licensed. **The brand it reproduces is
not, and is not available for reuse at all.**

The brand covers:

- The University of Bristol name, crest and logo.
- The Bristol Flight Lab name, bird-and-aircraft mark and wordmark.
- The colour palette, including Bristol red `#B01C2E` and the accent colours.
- The visual design of the page layouts, including the red band, the rule, the
  slanted edge, and the placement of the marks.

In this repository that means the SVG files in `dist/assets/brand/`, and the colour
and layout values in `dist/stylesheets/flightlab.css` where they reproduce the
design. See [flightlab-brand](https://github.com/BristolFlightLab/flightlab-brand).

If you are given permission to build on this code for anything else, remove
`dist/assets/brand/`, change the colours and restyle the layouts, so that your site
cannot be mistaken for University of Bristol or Bristol Flight Lab material.
Permission to reuse the code would never extend to the brand.
